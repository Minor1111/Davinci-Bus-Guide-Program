API 키 설정

키는 이 브라우저(localStorage)에만 저장되고, 파일이나 저장소에는 남지 않아요. 비워 두면 키 없이 쓸 수 있는 기능만 동작해요.
지도·장소 검색. developers.kakao.com › 내 애플리케이션 › 앱 설정 › 앱 › 플랫폼 키 › JavaScript 키. 같은 화면의 'JavaScript SDK 도메인'에 이 페이지 주소()를 등록하고, '카카오맵 › 사용 설정'을 ON으로 해 주세요.
실시간 도착·혼잡도. data.go.kr에서 '경기도_버스도착정보 조회'와 '경기도_정류소 조회'를 활용신청한 뒤 마이페이지의 일반 인증키. 신청 직후에는 반영까지 1~2시간 걸릴 수 있어요.
